# Task Plot Brief

## Task

- Title: Loss Aversion / Framing Task
- Construct: loss aversion / framing effects / risky choice
- Paradigm: sure-vs-gamble decisions under gain, loss, and mixed frames.

## Rows

- Gain frame: sure keep amount vs risky keep-all/keep-none option.
- Loss frame: sure loss amount vs risky full-loss/no-loss option.
- Mixed frame: sure amount vs mixed gain-loss lottery.

## Trial Timeline

1. Fixation: 400-700 ms jittered fixation, no response.
2. Decision: 4000 ms. Show frame label, scenario, safe option, and gamble option. Press F for safe, J for gamble.
3. Feedback: 700 ms. Show chosen option or timeout feedback.
4. ITI: 400-800 ms jittered fixation, no response.

## Notes

- Offer parameters are sampled from condition-specific offer banks.
- Feedback acknowledges the choice; it does not resolve a separate lottery outcome on screen.
